### Files vendored here (unmodified)

| File | Role |
|---|---|
| `transparent.py` | the masking/restoring mitmproxy addon (the engine) |
| `shield_defaults.py` | built-in rule definitions and defaults |
| `event_store.py` | local SQLite event log used by the engine |
| `credential_labels.py` | credential label tables |
| `audit_signals.py` | audit signal helpers imported by the engine |
| `ner_engine.py` | optional local NER model support (disabled in this deployment) |

These files are byte-identical to the upstream commit above. This deployment does not
patch them; configuration is supplied at runtime through `config.json` generated by
`entrypoint.mjs`.

### Deliberately NOT vendored

- `panel.py` (Flask control panel) and `audit_engine.py` — this deployment never exposes
  or runs the panel, so the ~41 MB panel process is omitted.
- `frontend/`, `src-tauri/` (desktop shell), tests, and build scripts.

### Licence compliance

This repository (`ply1omnir/freellmapi-render`) is public, ships the complete
corresponding source of the maskit engine as used in the deployed image, and keeps the
upstream licence text alongside it. The engine runs as a separate unmodified program
invoked by this deployment's own entrypoint.

## Other components

- mitmproxy (https://github.com/mitmproxy/mitmproxy), MIT licence — installed from PyPI.
- CPython 3.12 standalone builds via `uv` (https://github.com/astral-sh/uv).
- FreeLLMAPI (https://github.com/tashfeenahmed/freellmapi) — the base image.
